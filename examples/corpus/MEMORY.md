# Index

L'index est le routeur du rappel. Les accroches sont derivees des descriptions :
les regenerer avec `perctl index --sync`.

- [Decision: pas de base vectorielle](decision-pas-de-base-vectorielle.md) — Le corpus reste en markdown indexe, sans base vectorielle : le goulot est la curation, pas la recuperation
- [Feedback: un fait par note](feedback-un-fait-par-note.md) — Une note porte un seul fait : au-dela, elle ne peut plus etre ni dedoublonnee ni perimee proprement
- [Project: adoption memory kit](project-adoption-perimeter.md) — L'adoption commence par le lint en CI seul
- [Reference: index est le routeur](reference-index-est-le-routeur.md) — Une note absente de l'index est ecrite mais jamais lue : l'index est le routeur du rappel, pas une table des matieres de confort
- [User: equipe plateforme](user-equipe-plateforme.md) — L'equipe plateforme possede le corpus et arbitre les promotions de proposed vers canon
